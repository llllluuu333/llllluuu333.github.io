01WEB · PWA

Focus · 每日计划

把日程、番茄钟、饮食与健身训练收进一个可离线使用的网页 App，数据完全保存在本地、属于用户自己。

  • 时间轴日程：点击任意时段快速添加计划，今天 / 本周双视图，任务进度与专注时长统计
  • 番茄钟专注：15 / 25 / 45 / 60 分钟计时，可关联具体任务并累计专注数据
  • 饮食与健身：热量及三大营养素记录、内置动作库的训练打卡
  • 本地优先 PWA：localStorage 持久化 + JSON 导入导出，Service Worker 离线可用，可「添加到主屏幕」

02iOS · SWIFTUI

MistakeLoop · 错题闭环学习助手

知识库沉淀 + 错题间隔重复复习 + 薄弱点地图，为考研场景打造「记录 — 复习 — 掌握」的完整闭环。
